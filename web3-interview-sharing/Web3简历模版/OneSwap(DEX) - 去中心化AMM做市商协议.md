### **OneSwap - DEX 平台优化与维护** (2024.12 - 至今) - 丰富版

​		OneSwap 是基于智能合约的去中心化交易协议，融合 AMM（自动化做市商）与链上订单簿模式。平台支持用户自由上币（无需许可、无上币费用）、Swap 交易、限价单挂单、流动性提供、手续费分成与链上治理功能，并配套 OneSwap Wallet 提供一站式链上交易体验。采用恒定乘积做市商模型为市场提供连续报价，同时支持链上订单簿存储与撮合，用户可按固定价格挂买卖单。2024年加入该项目团队，我主要负责系统性能优化、多链扩展、安全维护与功能迭代。

### **技术栈**

- **后端**：Go、Gin、Gorm、Redis、PostgreSQL、gRPC
- **区块链**：Solidity、EVM、Hardhat、ethers.js
- **链上交互**：Go-Ethereum、多链 RPC
- **监控**：Prometheus + Grafana

### **核心职责**

* **链上数据同步系统优化与维护**：优化现有区块扫描 + 事件日志监听双通道架构，持续改进 Swap/Mint/Burn/Sync 等合约事件的解析与处理流程。维护 Block Hash 校验机制，优化 Reorg 检测与自动回滚逻辑，确保数据最终一致性。优化异步事件消费、分区处理、幂等写入、批处理落库等机制，提升系统吞吐量与数据可靠性。维护并扩展事件派发器（Dispatcher），支持多链、多合约、多事件类型的灵活扩展。优化区块指针与偏移量（Offset）管理系统，提升同步状态的可恢复性与可重放能力。

- **限价单与订单簿系统维护与性能优化**：维护现有订单存储结构（SkipList / Price Bucket / 时间优先队列），持续优化最优价查询和撮合效率。优化价格优先 + 时间优先的撮合引擎，维护部分成交、批量撮合、深度一致性以及撮合回放功能。维护链上执行的签名验证（ECDSA）、Nonce 管理、链上结算批处理（Batch Settlement）流程。优化撮合 → 校验 → 组装交易 → 广播 → 回执追踪的链上结算流水线，确保链上状态与链下订单簿一致性。维护订单生命周期管理功能，包括创建、修改、撤单、成交、失效清理等。

- **链上调用性能优化与区块同步加速**：优化现有 Batch RPC 机制，合并大量离散的区块查询、事件查询、合约读取，进一步减少 RPC 往返 60%+。优化 Multicall 合约批量读取策略，减少接口调用数量，降低 RPC 节点压力。重构区块扫描调度器，实现动态并发调度、连接池复用、指数退避重试、速率限制与优雅降级。引入读缓存、静态数据预加载、无效调用剪枝等优化，减少重复解析负担。使系统整体的区块同步速度在原有基础上提升 35%+，在高负载链环境下保持稳定。

- **多链部署环境维护与链适配层扩展**：维护现有 Chain Adapter Layer，持续优化各链 RPC、交易回执格式、Block Structure 等差异的统一处理。维护配置化的 Chain Registry，支持快速接入新链（如 ETH、BSC、Polygon、Arbitrum 等）。优化多链实例运行框架，改进多链进程隔离、自动扩缩容、节点故障自动切换机制。统一并优化多链事件解析流程，确保所有链的事件在高层 API 中保持一致行为。

- **合约交互测试与安全审计支持**：维护并扩展合约交互测试脚本，完善模拟场景、状态迁移测试，覆盖正常与异常路径。持续输出 Gas Report，分析关键函数的 Gas 结构与优化空间。修复审计团队新发现的问题，包括重入风险、算术精度误差、边界溢出、异常状态处理等。使用 fuzzing / property test 持续检查撮合、同步、结算等关键流程的稳定性与一致性。为审计团队提供事件追踪数据、调用回执、交互记录，支持快速验证修复结果。参与新功能的安全审计，提供合约交互用例、Gas report，并修复潜在安全问题。
