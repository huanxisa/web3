# **2024-12 - 2025-11** **Spaace** 区块链后端开发工程师

---

## 项目名称
**Spaace 游戏化 NFT 市场和聚合器** (Spaace Platform)

---

## 技术栈

**后端：** Golang (Gin, GORM, Go-Ethereum) + MySQL + ElasticSearch + Redis

**消息队列：** RabbitMQ

**NFT 技术：** ERC-721/ERC-1155 标准、IPFS/Arweave 去中心化存储

**部署运维：** Kubernetes (K8s) + Docker + Prometheus + Grafana

**核心合约：** Solidity

**其他：** WebSocket 实时推送、多链 RPC 节点管理

---

## 项目介绍

Spaace 是一个成立于 2022 年的游戏化 NFT 市场和聚合器，专注于通过沉浸式游戏化体验和社区激励机制，将 NFT 交易者转化为游戏玩家。平台整合多个主流 NFT 市场（如 OpenSea、Blur、LooksRare 等）的流动性，为用户提供最优价格和一站式交易体验。核心创新包括 Battle Pass 系统、任务系统（Quests）、XP/积分奖励机制，以及 100% 收入分享给社区的独特模式。

**2024年加入团队后，主要负责系统优化重构、新功能迭代和多链扩展工作。**

---

## 职责描述

**1. NFT 聚合引擎优化与重构：** 重构多市场 NFT 数据聚合服务，优化 OpenSea、Blur、LooksRare 等市场的数据同步机制。将原有的单一轮询模式重构为事件驱动架构，结合 WebSocket 实时推送和定时轮询，提升数据同步效率 40%。优化智能路由算法，实现最优价格自动选择，帮助用户降低交易成本。

**2. 多链 NFT 支持扩展：** 扩展平台多链支持能力，从单链（Ethereum）扩展至 Ethereum、Polygon、BSC 等多条主流链。重构多链事件监听服务，实现统一的链上事件处理逻辑，支持不同链的 RPC 节点管理和故障转移。开发多链 NFT 数据统一管理模块，实现跨链 NFT 资产的聚合展示和交易。

**3. NFT 索引系统重构与性能优化：** 重构 NFT 资产索引服务，优化链上数据同步和元数据获取流程。基于 ElasticSearch 优化全文搜索系统，通过索引优化和查询重构，搜索响应时间从 300ms 降低至 150ms。实现增量索引机制，只更新变化的 NFT 数据，索引服务负载降低 40%。

**4. 游戏化系统新功能迭代：** 迭代优化 Battle Pass 和任务系统，新增多类型任务支持（交易任务、持有任务、社交任务等）。重构 XP/积分系统，优化 Redis 存储结构，支持高并发积分更新，系统并发能力提升 50%。实现任务完成度的实时计算和奖励分发机制。

**5. 社区收入分享系统优化：** 优化 100% 收入分享系统的计算和分发逻辑，重构收入分配算法，支持多种分配策略的灵活配置。优化智能合约交互，通过批量操作和 Gas 优化，奖励分发成本降低 30%。建立收入分配的可追溯系统，提升系统透明性。

**6. 系统性能优化与缓存重构：** 重构多级缓存架构，优化 Redis 缓存策略，缓存命中率从 70% 提升至 85% 以上。优化 API 响应性能，通过缓存预热、查询优化等手段，API 平均响应时间从 500ms 降低至 100ms。优化数据库查询性能，复杂查询响应时间降低 60%。

**7. 智能合约交互优化：** 优化 Solidity 合约调用模式，减少不必要的链上交互。通过批量操作和 Gas 价格预测，将 Gas 成本降低 25-30%。重构合约交互封装层，统一多链合约调用接口，提升代码可维护性。

**8. 监控与稳定性保障：** 完善基于 Prometheus + Grafana 的监控体系，新增关键业务指标监控。建立基于 ELK 栈的日志分析系统，提升问题排查效率。系统可用性从 98% 提升至 99.5% 以上。

## 技术难点及解决方案

**多链数据同步与一致性保障：** 重构多链事件监听服务，设计统一的事件处理逻辑，支持不同链的特性差异。实现多链 RPC 节点集群管理，包括健康检查、故障转移、负载均衡等功能。建立跨链数据对账机制，确保多链数据同步的准确性。

**高并发场景下的系统性能优化：** 重构缓存架构，实现多级缓存策略，优化热点数据访问路径。采用异步处理机制，通过 RabbitMQ 解耦业务逻辑，提升系统吞吐量。优化数据库查询，通过索引优化和查询重构，降低数据库压力。

**游戏化系统的实时性与准确性：** 采用事件驱动架构，通过 RabbitMQ 异步处理用户行为事件。使用 Redis 存储任务进度和积分数据，支持高并发读写。实现幂等性机制，防止重复计算和奖励重复分发。

**NFT 元数据索引的性能优化：** 实现元数据预取和缓存机制，提前获取热门 NFT 的元数据。使用 CDN 和本地缓存，加速元数据访问。实现增量索引，只更新新铸造或变更的 NFT 元数据。
