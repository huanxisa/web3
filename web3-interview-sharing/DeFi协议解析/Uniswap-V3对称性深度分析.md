# Uniswap V3 对称性深度分析

> 问题：x·y=k 是关于 x 和 y 对称的，但 V3 引入了"价格超过 Pb 则全为 token1，低于 Pa 则全为 token0"的边界条件，这破坏了对称性。这个先验假设是否有合理性？

---

## 一、对称性在哪里被打破的？

### 1.1 x·y=k 的对称性

原始公式 $x \cdot y = k$ 确实是 $x \leftrightarrow y$ 对称的：
交换 $x$ 和 $y$ 的位置，公式形式不变。

### 1.2 价格定义打破了对称性

对称性的破坏不是 V3 引入的，而是在 **定义价格的那一刻** 就已经发生了：

$$P = \frac{y}{x}$$

这一步选择了"用 $y$ 计价 $x$"，而不是反过来。

从此 $x$ 和 $y$ 就有了不同的经济含义：
- $x$（token0）= 被计价的资产（如 ETH）
- $y$（token1）= 计价单位（如 USDC）

**这个非对称性来自经济含义，而非数学结构本身。**

---

## 二、边界条件是"定义"而非"假设"

### 2.1 从价格公式推导边界行为

由 $x \cdot y = k$ 和 $P = y/x$，可以得到：

$$x = \sqrt{\frac{k}{P}} = \frac{L}{\sqrt{P}}$$

$$y = \sqrt{k \cdot P} = L\sqrt{P}$$

观察这两个函数的行为：

| 价格 $P$ | token0 储量 $x$ | token1 储量 $y$ |
|---------|----------------|----------------|
| $P \to 0$ | $x \to +\infty$ | $y \to 0$ |
| $P \to +\infty$ | $x \to 0$ | $y \to +\infty$ |
| $P = P_b$（上界） | $x \to 0$ | $y$ 很大 |
| $P = P_a$（下界） | $x$ 很大 | $y \to 0$ |

**结论：**

> 边界条件"$P = P_b$ 时 $x = 0$"和"$P = P_a$ 时 $y = 0$"**不是先验假设**，而是恒定乘积曲线 $x \cdot y = k$ 本身在价格趋向上界和下界时的**自然极限行为**。

V3 只是把这个无限延伸的曲线**截断**在 $[P_a, P_b]$ 区间内，截断点处的行为（某种 token 趋近于 0）就成了边界条件。

---

## 三、"非对称"公式的对称性隐藏在哪里？

### 3.1 虚拟储备偏移量看起来不对称

$$x_{offset} = \frac{L}{\sqrt{P_b}} \quad \text{（含上界）}$$

$$y_{offset} = L\sqrt{P_a} \quad \text{（含下界）}$$

**表面上**：$x$ 的偏移量用的是上界 $P_b$，$y$ 的偏移量用的是下界 $P_a$，看起来不对称。

### 3.2 实际上存在深层对称

**换一个角度看：**

- 当价格到达 $P_b$（上界），$x = 0$，此时需要 $x_{offset}$ 来"补足"虚拟储备
  - $x_{offset}$ 必然由**上界** $P_b$ 决定 ✓
- 当价格到达 $P_a$（下界），$y = 0$，此时需要 $y_{offset}$ 来"补足"虚拟储备
  - $y_{offset}$ 必然由**下界** $P_a$ 决定 ✓

**对称结构：** 每种 token 的偏移量，由该 token 被"耗尽"时对应的那个边界价格决定。

| token | 在哪个边界耗尽 | offset 由谁决定 |
|-------|-------------|---------------|
| token0（$x$） | 上界 $P_b$ | $L / \sqrt{P_b}$ |
| token1（$y$） | 下界 $P_a$ | $L \cdot \sqrt{P_a}$ |

这是完美对称的——只不过两个 token 被耗尽的方向相反（一个在高价，一个在低价），所以它们各自对应的是不同方向的边界。

---

## 四、如果颠倒 x 和 y 的定义会怎样？

### 4.1 重新定义价格

假设我们把价格定义为：

$$P' = \frac{x}{y}$$（token0/token1，即 ETH/USDC，单位是 ETH per USDC）

则所有公式都会"镜像翻转"：

- 当 $P'$ 很大（ETH 贬值，USDC 升值），$y \to 0$（USDC 被耗尽）
- 当 $P'$ 很小，$x \to 0$（ETH 被耗尽）

边界条件变成：
- 上界 $P'_b$：$y = 0$
- 下界 $P'_a$：$x = 0$

公式变成：

$$\left(y + \frac{L}{\sqrt{P'_b}}\right) \cdot \left(x + L\sqrt{P'_a}\right) = L^2$$

和原来的公式完全是**镜像结构**。

**结论：** 所谓的"非对称"，完全来自于价格方向的选择，数学结构本身是对称的。

---

## 五、从几何角度理解

### 5.1 双曲线的截断

恒定乘积曲线 $x \cdot y = k$ 是一条双曲线，关于直线 $y = x$ 完全对称。

```
y
|  \
|   \
|    \  ← x·y=k
|     \
|      ·  ← 当前点 (x₀, y₀)
|       \
|        \
+-------------- x
```

V3 在这条双曲线上截取一段：

```
y
|
|  [截断点A: y=0, x很大]
|
|   ·────────·  ← 截取的曲线段 [Pa, Pb]
|              [截断点B: x=0, y很大]
|
+-------------- x
```

截取端点处，一侧 $x=0$，另一侧 $y=0$，这是双曲线的渐近线行为，不是人为引入的非对称性。

---

## 六、真正引入非对称性的地方

虽然数学结构是对称的，但有一个地方确实引入了**人为的非对称性**：

**费率结构与 token 排序。**

Uniswap V3 规定 token0 和 token1 的顺序由合约地址大小决定（地址小的为 token0），这是工程实现上的任意约定，与数学无关。

---

## 七、总结

| 问题 | 答案 |
|------|------|
| $x \cdot y = k$ 是否对称？ | 关于 $x \leftrightarrow y$ 完全对称 |
| 对称性何时被打破？ | 定义 $P = y/x$ 的那一刻（赋予经济含义） |
| 边界条件是先验假设吗？ | 不是，是双曲线在价格边界处的自然极限行为 |
| V3 公式的非对称来自哪里？ | 来自"价格方向"的选择，不是数学结构本身 |
| 颠倒 $x$ 和 $y$ 的定义会怎样？ | 得到完全镜像对称的公式，数学等价 |
| 深层对称是什么？ | 每种 token 的虚拟偏移量，由该 token 被耗尽时对应的边界决定，结构完全对称 |

> **核心洞察：**
> $x \cdot y = k$ 的对称性没有被破坏，它被"转移"到了更深的层次——token0 在高价被耗尽，token1 在低价被耗尽，这两件事是完全对称的，只是方向相反。非对称的外表，来自于我们选择了一个固定的"价格方向"来描述这个系统。
