#### 任务12：理解多链概念（15分钟）

**阅读理解**：

**为什么有这么多网络？**

1. **以太坊主网**
   - 最安全、最去中心化
   - 但Gas费贵、速度慢
   - 适合：高价值交易

2. **Layer 2（L2）**
   - 基于以太坊的扩容方案
   - 便宜、快速
   - 示例：Arbitrum、Optimism
   - 适合：日常交易

3. **侧链**
   - 独立的区块链
   - 与以太坊兼容
   - 示例：Polygon
   - 适合：低成本应用

4. **测试网**
   - 完全免费
   - 用于开发测试
   - 没有真实价值

**你的地址在所有网络都一样！**
- 同一个地址可以在多个网络使用
- 但每个网络的余额独立
- 切换网络就像切换"平行世界"

**完成标志**：
- [ ] 理解为什么有多个网络

### 第六部分：安全知识（30分钟）⭐⭐⭐⭐⭐

#### 任务13：学习安全知识（30分钟）

**必读安全知识**：

**1. 助记词安全（生命线！）**

✅ **应该做：**
- 手写在纸上，放在安全的地方
- 可以分成两部分存储（前6个+后6个分开）
- 使用金属助记词板（防火防水）
- 告诉家人助记词的位置（万一你出意外）

❌ **绝对不要：**
- 在线存储（云盘、笔记软件、邮箱）
- 截图或拍照
- 复制粘贴到任何地方
- 告诉任何人（包括客服、"技术支持"）
- 在任何网站输入（MetaMask官方也不会要求）

**2. 密码安全**

✅ **应该做：**
- 设置强密码（大小写+数字+符号）
- 与其他网站密码不同
- 使用密码管理器（如1Password、Bitwarden）

❌ **不要：**
- 使用简单密码（123456、password等）
- 在浏览器保存密码（不安全）

**3. 钓鱼防范**

⚠️ **常见骗局：**

| 骗局 | 特征 | 防范 |
|------|------|------|
| 假水龙头 | 要求输入助记词 | 真水龙头只要地址 |
| 假客服 | 主动联系你"帮助" | 官方不会主动联系 |
| 假空投 | 声称免费领代币 | 需要"授权"你的钱包 |
| 钓鱼网站 | 网址很相似 | 仔细检查URL |

✅ **安全习惯：**
- 只从官方渠道下载MetaMask
- 仔细检查网站URL
- 不点击陌生链接
- 大额操作前多次确认

**4. 交易安全**

✅ **转账前检查清单：**
- [ ] 接收地址是否正确？（最好复制粘贴后再核对）
- [ ] 金额是否正确？
- [ ] 小数点是否正确？（0.1 vs 1.0）
- [ ] Gas费是否合理？
- [ ] 网络是否正确？

**5. DApp连接安全**

⚠️ **连接DApp时：**
- 只连接信任的网站
- 查看请求的权限
- 不要授权无限额度（approve unlimited）
- 定期检查已连接的网站
- 不用的DApp及时断开

**实践练习**：

1. [ ] **设置密码管理**
   - 确保MetaMask密码足够强
   - 记录到密码管理器

2. [ ] **检查已连接的网站**
   - MetaMask → 设置 → 已连接的网站
   - 断开所有不认识的网站

3. [ ] **阅读安全文档**
   ```
   https://github.com/slowmist/Blockchain-dark-forest-selfguard-handbook/blob/main/README_CN.md
   ```
   - 这是慢雾公司的《区块链黑暗森林自救手册》
   - 至少浏览目录，了解有哪些风险

**完成标志**：
- [ ] 助记词已安全备份（纸质）
- [ ] 设置了强密码
- [ ] 了解常见骗局
- [ ] 知道如何安全使用钱包
