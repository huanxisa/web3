# 如何发币

本教程将指导您如何在以太坊网络上发行自己的代币（Token）。我们将使用OpenZeppelin库来创建符合ERC-20标准的代币。

## 1. 准备工作

### 1.1 环境要求
- 谷歌浏览器
- MetaMask钱包（已安装并配置）
- 测试网ETH（用于部署合约）

### 1.2 开发工具
- [Remix IDE](https://remix.ethereum.org/) - 在线Solidity开发环境

## 2. 使用Remix IDE发币（推荐新手）

### 2.1 创建代币合约
1. 访问 [Remix IDE](https://remix.ethereum.org/)
2. 创建新文件：`MyToken.sol`
<img width="1512" height="869" alt="image" src="https://github.com/user-attachments/assets/f8527f0e-b1c6-4212-a1af-7ff8c5fec25a" />

<img width="1512" height="869" alt="image" src="https://github.com/user-attachments/assets/5eed0a63-5101-46b1-91b0-24746499ca83" />

4. 复制以下代码：

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

import {ERC20} from "@openzeppelin/contracts/token/ERC20/ERC20.sol";
import {Ownable} from "@openzeppelin/contracts/access/Ownable.sol";

contract MyToken is ERC20, Ownable {
    constructor()
        ERC20("MyToken", "MTK")
        Ownable(msg.sender)
    {
        mint(msg.sender, 100000 ether);
    }

    function mint(address to, uint256 amount) public onlyOwner {
        _mint(to, amount);
    }
}
```


### 2.2 编译合约
1. 在Remix中切换到"Solidity Compiler"标签
2. 选择编译器版本（0.8.0或更高）
3. 点击"Compile MyToken.sol"
4. 确保没有编译错误

## 5. 总结

发行代币是区块链项目的重要步骤，但需要：
- 充分理解ERC-20标准
- 进行充分的测试
- 考虑代币经济学
- 重视安全性
- 制定营销策略
