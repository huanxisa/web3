# 如何发行自己的专属数藏（NFT）


[📺 学习视频](https://bilibili.com/video/BV1XmaAzfEhv/)   
本教程将指导您如何创建和发行自己的NFT（非同质化代币），也称为数字藏品。我们将使用ERC-721标准来创建独特的数字资产。

## 1. 什么是NFT？

### 1.1 NFT基本概念
- **非同质化**：每个NFT都是独一无二的
- **不可分割**：不能像代币那样分割
- **可验证**：通过区块链验证所有权
- **可交易**：可以在市场上买卖

### 1.2 NFT应用场景
- 数字艺术品
- 游戏道具
- 虚拟土地
- 身份证明
- 收藏品
- 音乐版权

## 3. 使用Remix创建NFT合约

### 3.1 创建NFT合约
在Remix中创建 `MyNFT.sol`：

```solidity
// SPDX-License-Identifier: MIT
// Compatible with OpenZeppelin Contracts ^5.5.0
pragma solidity ^0.8.27;

import {ERC721} from "@openzeppelin/contracts/token/ERC721/ERC721.sol";
import {ERC721URIStorage} from "@openzeppelin/contracts/token/ERC721/extensions/ERC721URIStorage.sol";
import {Ownable} from "@openzeppelin/contracts/access/Ownable.sol";

contract MyToken is ERC721, ERC721URIStorage, Ownable {
    uint256 private _nextTokenId;

    constructor(address initialOwner)
        ERC721("MyToken", "MTK")
        Ownable(initialOwner)
    {}

    function safeMint(address to, string memory uri)
        public
        onlyOwner
        returns (uint256)
    {
        uint256 tokenId = _nextTokenId++;
        _safeMint(to, tokenId);
        _setTokenURI(tokenId, uri);
        return tokenId;
    }

    // The following functions are overrides required by Solidity.

    function tokenURI(uint256 tokenId)
        public
        view
        override(ERC721, ERC721URIStorage)
        returns (string memory)
    {
        return super.tokenURI(tokenId);
    }

    function supportsInterface(bytes4 interfaceId)
        public
        view
        override(ERC721, ERC721URIStorage)
        returns (bool)
    {
        return super.supportsInterface(interfaceId);
    }
}
```

## 4. 准备NFT元数据

### 4.1 创建元数据JSON
```json

  "name": "我的第一个NFT",
```

## 5. 铸造NFT

### 5.1 在Remix中铸造
1. 在部署的合约中调用 `mintNFT` 函数
2. 参数：
   - `to`: 接收者地址
   - `tokenURI`: IPFS元数据链接
3. 确认交易

### 5.2 验证NFT
1. 在Etherscan查看交易
2. 在OpenSea查看NFT
3. 确认元数据正确显示

## 6. 高级NFT功能

### 6.1 批量铸造
```solidity
function batchMint(address[] memory to, string[] memory tokenURIs) 
    public 
    onlyOwner 
{
    require(to.length == tokenURIs.length, "Arrays length mismatch");
    
    for (uint256 i = 0; i < to.length; i++) {
        mintNFT(to[i], tokenURIs[i]);
    }
}
```

### 6.2 设置铸造价格
```solidity
uint256 public mintPrice = 0.01 ether;

function mintWithPrice(string memory tokenURI) 
    public 
    payable 
    returns (uint256) 
{
    require(msg.value >= mintPrice, "Insufficient payment");
    
    _tokenIds.increment();
    uint256 newTokenId = _tokenIds.current();
    _mint(msg.sender, newTokenId);
    _setTokenURI(newTokenId, tokenURI);
    
    return newTokenId;
}
```

### 6.3 设置铸造限制
```solidity
uint256 public maxSupply = 1000;
uint256 public maxMintPerAddress = 5;
mapping(address => uint256) public mintedCount;

function mintWithLimit(string memory tokenURI) 
    public 
    returns (uint256) 
{
    require(_tokenIds.current() < maxSupply, "Max supply reached");
    require(mintedCount[msg.sender] < maxMintPerAddress, "Max mint per address reached");
    
    mintedCount[msg.sender]++;
    return mintNFT(msg.sender, tokenURI);
}
```
