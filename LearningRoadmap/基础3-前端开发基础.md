## 任务 :two:: 文档资料:point_right: Next.js 全栈框架

课程视频和课件的详细链接: https://github.com/MetaNodeAcademy/nextjs-courses/tree/main

**学习要点:**
1. :white_small_square: React 核心特性
:book: 虚拟 DOM 原理/组件化开发优势  
:white_check_mark: 理解 React 与传统 JS 开发差异

2. :white_small_square: JSX 语法
:book: 嵌入式 HTML/CSS/JS 混合编程范式  
:white_check_mark: 实现动态内容渲染模板

3. :white_small_square: 组件与事件
:book: 函数组件与类组件对比  
:wrench: 实战：构建可交互按钮组件

4. :white_small_square: 状态管理
:book: `useState`/`props`数据流控制  
:white_check_mark: 实现父子组件数据双向绑定

5. :white_small_square: 表单处理  
:book: 受控组件与非受控组件选择策略  
:exclamation: 注意：表单验证安全规范

6. :white_small_square: 生命周期
:book: 组件挂载/更新/销毁阶段控制  
:white_check_mark: 实现数据懒加载功能

7. :white_small_square: Hooks 进阶
:book: `useEffect`/`useContext`/`useRef`深度应用  
:wrench: 实战：全局状态管理方案

8. :white_small_square: 路由系统  
:book: React Router 动态路由配置  
:white_check_mark: 实现多页面导航与权限控制

9. :white_small_square: Redux 或者 zustand 状态库  
:book: Action/Reducer/Store 工作流设计  
:white_check_mark: 构建跨组件状态共享系统
