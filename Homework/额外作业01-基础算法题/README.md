# 额外作业01：基础 Solidity 算法题

> 作业要求：`../homework01.md`

## 作业说明

这是一组基础 Solidity 编程练习题，与其他大小作业**完全独立**，需单独完成。

## 题目列表

### 题目1：投票合约（Voting Contract）
**文件**：`contracts/Voting.sol`
- [ ] `mapping` 记录候选人得票数
- [ ] `vote(candidate)` 函数：用户投票
- [ ] `getVotes(candidate)` 函数：查询得票数
- [ ] `resetVotes()` 函数：重置所有票数

### 题目2：反转字符串（Reverse String）
**文件**：`contracts/StringUtils.sol`
- [ ] 输入 `"abcde"`，输出 `"edcba"`

### 题目3：整数转罗马数字（Integer to Roman）
**文件**：`contracts/RomanNumerals.sol`
- [ ] 实现 LeetCode 12 题（整数转罗马数字）

### 题目4：罗马数字转整数（Roman to Integer）
**文件**：`contracts/RomanNumerals.sol`
- [ ] 实现 LeetCode 13 题（罗马数字转整数）

### 题目5：合并两个有序数组（Merge Sorted Array）
**文件**：`contracts/ArrayUtils.sol`
- [ ] 将两个有序数组合并为一个有序数组

### 题目6：二分查找（Binary Search）
**文件**：`contracts/ArrayUtils.sol`
- [ ] 在有序数组中查找目标值，返回索引
