# 小作业03：NFT 盲盒项目实战

> 参考学习资料：`../Solidity智能合约开发 - NFT盲盒项目实战(学习资料).md`
> 参考示例代码：`../study_code/nft-blindbox/`（官方示例，可参考但需独立实现）

## 作业目标

独立实现一个集成 Chainlink VRF 可验证随机数的 NFT 盲盒合约，支持 UUPS 可升级模式。

## 核心合约

### NFTBlindBox.sol（主合约，UUPS 可升级）
- [ ] 继承 ERC721（OpenZeppelin）
- [ ] 集成 Chainlink VRF V2（可验证随机数）
- [ ] 盲盒购买（`purchaseBlindBox()`）：支付 ETH → 铸造 NFT → 请求 VRF 随机数
- [ ] 盲盒揭示（`revealBlindBox(tokenId)`）：VRF 回调后，按稀有度分配属性
- [ ] 稀有度分配算法（5档：Common/Uncommon/Rare/Epic/Legendary）

### 销售机制
- [ ] 分阶段销售：白名单阶段 → 公开销售阶段
- [ ] 白名单管理：`addToWhitelist()` / `removeFromWhitelist()`
- [ ] 价格控制：白名单价格 vs 公开价格
- [ ] 最大供应量限制（`MAX_SUPPLY`）

### 元数据管理
- [ ] 盲盒 URI（揭示前，统一占位图）
- [ ] 揭示后 URI（基于 IPFS，每个 tokenId 独立元数据）
- [ ] `tokenURI()` 动态返回

### UUPS 升级
- [ ] 使用 `@openzeppelin/hardhat-upgrades` 部署
- [ ] V2 版本合约（添加新功能）

## 测试覆盖（test/）
- [ ] ERC721 基础功能测试
- [ ] 购买盲盒测试（价格验证、供应量限制、白名单权限）
- [ ] VRF Mock 测试（模拟随机数回调）
- [ ] 稀有度分配测试（概率分布验证）
- [ ] 揭示流程测试
- [ ] 升级测试（V1 → V2）

## 部署（ignition/ 或 scripts/）
- [ ] UUPS 代理部署脚本
- [ ] 配置 Chainlink VRF Subscription
- [ ] 部署到 Sepolia 测试网

## 技术栈
- Solidity 0.8.24
- OpenZeppelin Contracts（ERC721 + UUPS）
- Chainlink VRF V2
- Hardhat 3 + TypeScript
- IPFS（元数据存储）
