# 管理学 · MBA · 财务（经世致用学习地图）

> **定位**：不追学术前沿与思想史，服务两个实用目标——**投资看企业**、**业务经营**。

## 一、三个名词：范围、重叠、侧重

### 1.1 各自管什么

| | 管理学 | MBA | 财务（会计 / 审计） |
|---|---|---|---|
| **本质** | 一门（组）学科 | 一种培养 / 学位形态 | 一套信息记录与鉴证体系 |
| **核心问题** | 组织如何达成目标 | 管理者如何做综合决策 | 经济活动如何被如实记录、如何被验证可信 |
| **典型产出** | 理论、框架 | 案例决策能力、通用管理技能 | 报表、底稿、审计意见 |

一句话：

- **管理学** = 知识体系本身  
- **MBA** = 用商科知识（含管理学、财务等）训练「当管理者」的路径  
- **会计 / 审计** = 经营与投资的「数字语言」及其可信度保障  

### 1.2 重叠关系

```
        ┌──────────── 管理学 ────────────┐
        │  战略 / 组织 / 领导 / 运营…     │
        │         ┌──────────┐           │
        │         │ 财务管理 │ ←── 与会计交汇的决策层
        │         └──────────┘           │
        └──────────────┬─────────────────┘
                       │ 被 MBA 打包讲授
                       ▼
              ┌────── MBA ──────┐
              │ 管理学各模块    │
              │ + 会计/财务    │
              │ + 营销/运营等  │
              └────────┬───────┘
                       │ 其中一块深度展开
                       ▼
              ┌── 会计 / 审计 ──┐
              │ 记账规则与报表  │
              │ 内控与鉴证      │
              └─────────────────┘
```

重叠三块：

1. **财务管理 ↔ 会计**：会计记历史；管理用数字做决策。  
2. **MBA ∩ 管理学**：主干课 ≈ 管理学应用版，更重案例而非研究。  
3. **MBA ∩ 会计/审计**：通常有财务会计 / 管理会计入门；审计多一笔带过。

### 1.3 「学完 MBA = 财务+管理都覆盖了？」——不成立

| 表述 | 评判 |
|---|---|
| 学完 MBA，财务和管理就都涵盖了 | **过强** |
| 更准确 | 管理与财务的**通识决策层**基本涵盖 |

- MBA 财务 ≈「管理者用的财务」，不是会计师 / 审计师深度。  
- MBA 管理 ≈「应用型通识」，不是管理学学科全集。  
- 经世致用场景下：**不必再系统学管理学**；**财务侧必须单补一层（读表 + 现金流质量）**。

### 1.4 经世致用下：MBA 之外还补什么（总览）

| | MBA 已大致覆盖 | 仍建议单学 | 可永久不学（就本目标） |
|--|----------------|------------|------------------------|
| 管理 | 战略/组织/营销/领导力通识 | 管理会计、运营工具、极简激励 | 学科史、研究前沿、领导力流派 |
| 财务 | 入门会计、基础公司金融 | **读表+现金流质量**、实用公司金融；审计只需意识 | 会计分录体系、审计执业、准则研究 |

## 二、公共核心（投资 + 经营共用，优先学一遍）

学一次，两边复用：

| # | 模块 | 能做什么 | 停在哪 |
|---|------|----------|--------|
| 1 | 三张表 + 利润/现金流背离 | 判断赚的是纸面还是真钱 | 会读年报核心，不必做账 |
| 2 | 管理会计：成本、毛利、盈亏平衡 | 拆单元经济、指导定价/砍成本 | 会算贡献边际与盈亏平衡 |
| 3 | 商业模式 + 价值链 | 对接产业分析 | 能画一页「怎么赚钱」 |
| 4 | 激励与动机 | 看懂 KPI/股权/代理扭曲 | 能识别「人和目标拧着」 |
| 5 | 现金与账期 | 投资看风险、经营防断粮 | 懂应收/应付/库存占款 |

```
公共核心
├── 读表与现金流质量
├── 成本与单元经济
├── 商业模式 / 价值链
├── 激励与动机
└── 现金与账期
        │
        ├─► 投资加深：粉饰信号、杠杆、治理、估值直觉
        └─► 经营加深：预算、运营瓶颈、获客与人效、现金预测
```

## 三、场景 A：投资看企业

**目标**：值不值得关注 / 风险在哪 / 数字能不能信；与产业分析衔接。

### 3.1 财务（主战场）

| 模块 | 学什么 | 停在哪 |
|------|--------|--------|
| 读三张表 | 资产负债 / 利润 / 现金流勾稽；关键科目 | 能独立读年报核心页 |
| 利润 vs 现金流 | 经营现金流、自由现金流、利润质量 | 能判断纸面 vs 真钱 |
| 粉饰信号 | 应收暴增、存货异常、资本化、关联交易、商誉等 | 有检查清单即可 |
| 杠杆与偿债 | 有息负债、利息覆盖、期限结构 | 能判断周期赌博风险 |
| 公司金融直觉 | 折现大意、资本成本粗估、股/债含义 | 贵不贵、风险溢价够不够 |
| 审计意识（浅） | 意见类型、内控大意、何时更不可信 | 防踩雷，不学底稿 |

### 3.2 管理（为读懂生意）

| 模块 | 学什么 | 停在哪 |
|------|--------|--------|
| 战略工具 | 五力、价值链、定位、护城河类型 | 一页「这行怎么赚钱」 |
| 商业模式 | 收入来源、成本堆叠、规模优势 | 简单模式图 |
| 运营粗读 | 产能、库存、交付、周转 | 报表科目连回业务 |
| 激励与治理 | 股权激励、大股东、管理层动机 | 理解代理冲突 |

### 3.3 本场景后置

税务细节、合并报表深水、金融工具会计、估值建模高级技巧、管理思想史。

## 四、场景 B：业务经营

**目标**：定价、成本、交付、人、现金流不断——把业务跑顺。

### 4.1 管理（主战场）

| 模块 | 学什么 | 停在哪 |
|------|--------|--------|
| 管理会计 | 成本结构、贡献边际、盈亏平衡、预算偏差 | 能做月度经营账 |
| 运营 | 流程、瓶颈、库存/产能、交付、质量反馈 | 能改一条关键流程 |
| 组织与激励 | 分工、KPI、分成、销售/交付激励 | 规则不严重扭曲行为 |
| 营销与获客（实用） | 渠道、转化、LTV/CAC、留存 | 会算单元经济 |
| 战略（落地版） | 选客群、选品、取舍 | 能写一季度重点 |

### 4.2 财务（为经营保命）

| 模块 | 学什么 | 停在哪 |
|------|--------|--------|
| 现金流管理 | 收付款账期、库存占款、资金缺口预警 | 简易现金滚动预测 |
| 管理报表 | 毛利、费用率、人效等经营看板 | 每周/每月能决策 |
| 融资常识 | 借贷时机、稀释、契约大意 | 谈融资不慌 |
| 税务与合规（入门） | 相关税种、发票、合同风险 | 知边界，细节问专业人士 |
| 读表（轻量） | 正式报表与银行流水对应 | 比投资场景浅一档 |

### 4.3 本场景后置

审计执业、准则研究、学术组织理论、复杂并购估值。

### 5.2 统一课型：每门课「培养什么」（经世致用解读）

把五校不同课名映射成你要练的**能力**，而不是课号：

| 统一课型 | 典型课名 | 培养什么（能力） | 不培养什么 | 对你两端场景 |
|----------|----------|------------------|------------|--------------|
| **Financial Accounting / FRC** | 财务会计、财务报告与控制 | 把经济业务翻译成三张表；理解权责发生制；管理者视角读报表 | 审计程序、注册会计师做账速度、准则逐条 | 投资：必深；经营：够用即可 |
| **Managerial Accounting**（常并入 FRC 或会计选修） | 管理会计 | 成本、预算、差异、内部决策用数 | 对外披露规则 | 经营：必深；投资：拆单元经济 |
| **Corporate / Managerial Finance** | 公司金融、Finance 1/2 | NPV/IRR、资本成本、资本结构、投资与融资决策框架 | 卖方建模工厂、交易台细节 | 投资：估值直觉；经营：投扩产/融资判断 |
| **Microeconomics for Managers** | 经理经济学、Economic Analysis | 供需、定价、博弈与竞争、激励相容直觉 | 宏观计量、学术证明 | 两边：竞争与定价语言 |
| **Macro / BGIE** | 宏观与全球环境、政商关系 | 利率/通胀/政策如何冲击行业与企业 | 成为宏观经济学家 | 投资：周期与政策；经营：大气候感知 |
| **Statistics / Data / DMD** | 回归、Data Models Decisions、DSAIL | 用数据做推断与决策；分清相关与因果粗线条 | 成为数据科学家 | 两边：看报告、做实验不踩坑 |
| **Organizational Behavior / LEAD** | 组织行为、领导力、团队 | 激励、权力、文化、如何带人与被带 | 心理学研究前沿 | 经营：带团队；投资：治理与动机 |
| **Marketing** | 营销管理 | 定位、细分、渠道、客户价值 | 投放操盘手技能 | 经营：获客；投资：看增长是否可持续 |
| **Operations / TOM** | 运营、技术与运营 | 流程、产能、库存、交付、质量 | 工业工程专精 | 经营：主战场；投资：连周转率到业务 |
| **Strategy** | 战略、竞争战略 | 行业结构、定位、取舍、优势是否可持续 | 战略思想史 | 两边：对接产业分析 |
| **Ethics / LCA / LGST** | 问责、商业伦理与法 | 合规边界、治理、声誉与法律责任意识 | 律师执业 | 投资：踩雷防范；经营：合规底线 |
| **Communication** | 管理沟通 | 把分析变成可执行的叙事与说服 | 文学写作 | 两边：汇报与尽调沟通 |

### 5.3 五校培养哲学差异（帮你选「跟谁的地图」）

| 学校 | 核心课设计特点 | 更适合你用来对标什么 |
|------|----------------|----------------------|
| **HBS** | 一年固定 RC、强案例、通才总经理；FIN+FRC+战略+运营+营销+领导全开 | 「综合总经理 / 案例决策」广度地图 |
| **Wharton** | 固定核 + 灵活核；会计/金融/宏观/统计硬，分析强 | 「分析扎实的 MBA」；金融与会计底座清晰 |
| **Stanford GSB** | Analytic + Leadership + 自选 Management Foundations | 「领导力 + 自选深度」；一年级后几乎全选修 |
| **MIT Sloan** | 一学期紧核（会计+组织+经济+数据+沟通），功能课多选修 | 「量化决策 + 组织」；**OCW 可免费对照自学** |
| **Booth** | 几乎无统一课表；三门 Foundations + 8 类选 7 + 海量选修 | 「自由组合」；金融浓度高时很强，但要自律选题 |

### 5.4 MBA 核心课 vs 专业会计/审计培养（关键对照）

名校 **MBA 核心几乎都不含**「审计执业课」。审计深度在：

- 本科/硕士 **Accounting** 项目、**MAcc**、或 CPA 路径；  
- MBA 里通常只到「读表 + 内控/治理意识」（如 HBS 的 FRC、LCA）。

| | MBA 核心财务相关 | 会计硕士 / CPA 路径 |
|--|------------------|---------------------|
| 目标 | 管理者决策 | 记账、报告、鉴证 |
| 会计 | 读表、报告与控制 | 准则、分录、合并、税会差异 |
| 审计 | 极少或意识层 | 风险导向审计、底稿、意见类型实务 |
| 金融 | 公司金融决策 | 视项目而定，常弱于 Booth/Wharton 金融选修 |

→ 印证前文：学完 MBA 核心 ≠ 财务（会计/审计）全覆盖；你的经世致用路径应 **对标 MBA 核心广度 + 单补读表/质量分析**，而不是对标 CPA。

## 十、投资看企业：财务之外还需要什么

财务回答「数字是否漂亮、贵不贵、杠杆是否危险」。投资要做成判断，通常还缺下面几层（按优先级）：

### 10.1 知识栈总览

```
① 产业 / 赛道（中观）     ← 往往比财务报表更能决定长期回报
② 商业模式与竞争（微观生意）
③ 治理与人（谁在管、动机是否拧）
④ 宏观与周期（大气候，粗线条即可）
⑤ 市场与组合（怎么下单与承受回撤）← 按你是否实盘决定深度
⑥ 信息与研究流程（怎么收集与证伪）
⑦ 法律与交易规则（市场相关，够用即可）
```

财务（读表、质量、估值、资本结构）是 **⑧ 横切能力**：贯穿 ①–④ 的验证工具，不是唯一工具。

### 10.2 各块学什么、停在哪、主书

| 优先级 | 知识块 | 学什么 | 停在哪 | 主书 / 材料 |
|--------|--------|--------|--------|-------------|
| P0 | **产业分析** | 价值链/利润池、供需、技术与政策冲击、竞争格局 | 能画该行业一页图并说出钱在哪一环 | 《产业链分析学习计划》；Porter；券商行业深度报告 |
| P0 | **商业模式** | 收入怎么来、成本怎么堆、规模是否带来优势、客户是否锁定 | 一页 Canvas + 「若倒闭会因什么」 | 《商业模式新生代》；年报「业务概要」 |
| P0 | **竞争与护城河** | 五力、进入壁垒、替代品、是否可被颠覆 | 能判断优势是否 5–10 年仍在 | Porter；《巴菲特的护城河》 |
| P1 | **治理与激励** | 大股东、股权激励、关联交易、管理层承诺是否可信 | 能列出 3 个「人与股东可能冲突」点 | 年报治理章节；公司金融 Agency 章；《组织行为学》动机章 |
| P1 | **运营现实感** | 产能、库存、交付、回款是否支撑报表故事 | 报表科目能连回真实业务 | 《目标》；到产业里看研报/调研纪要 |
| P1 | **宏观与周期** | 利率、通胀、信用、地产/出口等如何传到该行业 | 能写「当前宏观对该行业的 3 条传导」 | Mankiw 宏观选章；Marks《周期》 |
| P2 | **市场微观结构** | 流动性、交易制度、涨跌停、做空限制（按市场） | 不因机制踩坑 | 交易所投资者手册 |
| P2 | **组合与风险** | 仓位、相关性、回撤、期望与方差直觉 | 不把「会看一家公司」当成「会管组合」 | Marks《投资最重要的事》；入门组合论选章即可 |
| P2 | **行为偏差** | 过度自信、锚定、损失厌恶、叙事陷阱 | 有自己的检查清单 | Kahneman《思考，快与慢》选读；或行为金融通俗读本 |
| P2 | **研究流程** | 假设→证据→证伪；一手/二手信息分级 | 每份结论旁标注证据等级 | 自己建模板；对标卖方报告结构学习 |
| P3 | **法规与披露** | 信披规则、内幕交易边界、退市风险 | 知红线 | 证监会/交易所规则导读 |
| P3 | **会计加深** | 合并、收入确认争议、行业特殊会计 | 用到再学 | 后置 |

### 10.3 和「只会财务」的差别（例子）

| 只懂财务时容易犯的错 | 补上非财务后 |
|----------------------|--------------|
| 利润好看就买 | 先问利润池是否在变、护城河是否在蚀 |
| 低估值就以为安全 | 可能是夕阳行业或治理陷阱（价值陷阱） |
| 模型很精致 | 关键假设（增速、利润率）来自产业，不是来自 Excel |
| 忽略人和股权结构 | 报表完美也可被掏空或定增伤害中小股东 |

### 10.4 建议投入比例（经世致用）

对「投资看企业」自学时间，可粗分为：

| 块 | 时间占比（约） |
|----|----------------|
| 产业 + 商业模式 + 竞争 | 35–40% |
| 财务读表 + 质量 + 估值直觉 | 30–35% |
| 治理 + 运营现实感 | 10–15% |
| 宏观周期（粗） | 5–10% |
| 组合 / 行为 / 流程 / 法规 | 10–15% |

### 10.5 最小可行「投资非财务」书单

1. Porter《竞争战略》（产业+竞争语言）  
2. 《商业模式新生代》或坚持自己画 Canvas  
3. 《产业链分析学习计划》+ 持续读行业报告  
4. Marks《周期》或《投资最重要的事》  
5. （可选）《思考，快与慢》选读行为偏差  

以上与 §6.C 财务书单**并行**，不是替代。

### 11.1 先建信息分级（一切方法的底座）

| 等级 | 含义 | 典型来源 | 使用规则 |
|------|------|----------|----------|
| **L0 原始事实** | 可核对、有责任主体 | 年报/半年报/招股书、交易所公告、统计局、央行、海关、专利局、法院文书 | **结论必须尽量锚在 L0** |
| **L1 整理事实** | 对 L0 的汇编，较少观点 | 巨潮/EDGAR 原文、公司官网产品页、行业协会公开数据 | 可当证据，注明出处页码/日期 |
| **L2 他人分析** | 带框架与观点 | 券商深度、咨询白皮书、高质量媒体长文、专家访谈纪要 | **当假设与线索，不当结论** |
| **L3 传闻/情绪** | 难核实 | 股吧、群聊、短视频金句、匿名爆料 | 只触发「去验证」，禁止直接进决策 |

**方法论第一条：** 每写一条判断，旁注 `证据等级 L0–L3` + `来源` + `日期`。等级不够就降级措辞（「可能」「待证」）。

### 11.2 按知识块：信息从哪获取（渠道地图）

| 你要的信息（§十） | 优先渠道（由高到低） | 怎么取 |
|------------------|----------------------|--------|
| **财务数字与质量** | 巨潮 / EDGAR 年报；附注；审计意见；证监会处罚 | 固定读：主表 → 附注关键科目 → 关联交易 → 股权激励 → 「关键审计事项」 |
| **商业模式** | 年报「主营构成」；招股书业务章；官网/产品；客户合同表述（若披露） | 自己填 Canvas：谁付钱、为何付钱、成本卡在哪 |
| **产业 / 利润池** | 行业协会数据；统计局/工信部；海关；券商「行业深度」；龙头招股书行业章 | 先画环节图，再找每环「量×价×利润率」公开数据 |
| **竞争与份额** | 多公司年报交叉；第三方市占（慎用 L2）；招标/中标公告；应用商店/流量榜（消费互联网） | **至少 2 个独立来源**对份额；对不上就写「未知」 |
| **治理与人** | 年报治理、实际控制人、股权质押；工商信息；董监高简历；激励草案 | 问：谁受益、谁能掏空、承诺能否核验 |
| **运营现实感** | 产能利用率、存货周转（报表）；工厂/门店探访（若可）；供应链调研纪要（L2）；招聘 JD（侧面） | 报表故事 vs 业务常识是否打架 |
| **宏观传导** | 央行、统计局、财政部；美联储等（若投海外）；Marks 式周期框架 | 只写「对该行业的 3 条传导」，不写宏观作文 |
| **法规红线** | 证监会/交易所规则；公司诉讼公告 | 知边界即可 |
| **情绪与预期** | 卖方一致预期、资金流向（L2/L3） | 仅用于「市场定价了什么」，不用于「真相是什么」 |

|------|------|

| 美股披露 | https://www.sec.gov/edgar |
| 中国宏观 | http://www.stats.gov.cn/ · http://www.pbc.gov.cn/ |

### 11.3 可复用的研究流程（培养的核心方法论）

把每一次「看行业 / 看公司」收成同一条流水线：

```
1. 选题     我要回答的「一个问题」是什么？（一句话）
2. 假设     先写 3 条可证伪假设（不是先搜爽文）
3. 资料单   列出本问题需要的 L0 清单（年报哪几节、哪类宏观数据）
4. 采集     只按清单下载/摘录，禁止无限开新标签页
5. 交叉     同一事实 ≥2 源；冲突则降级或标注争议
6. 建模直觉  产业一页图 / Canvas / 简单量本利（不必复杂 Excel）
7. 证伪     主动找「假设不成立」的证据（最重要一步）
8. 结论     结论 + 证据等级 + 自知未知 + 后续跟踪指标
9. 复盘     3–6 个月后对照：哪条假设错了、信息错在哪一层
```

**方法论第二条：** 先问题与假设，后搜索。反过来会变成「被推送喂养」。

### 11.4 「获取能力」怎么练（刻意练习，不是收藏网站）

| 练什么 | 具体动作 | 频率建议 | 合格标准 |
|--------|----------|----------|----------|
| **定位 L0** | 打开一家公司年报，10 分钟内找到：收入结构、前五大客户/供应商（若有）、关联交易、审计意见 | 每周 1 家 | 不靠别人摘要能自己翻到 |
| **信息分级笔记** | 任意结论旁强制写 L0–L3 | 每次研究 | 抽查时能说出证据从哪来 |
| **一页产业图** | 选一个熟悉消费/科技赛道，只画环节与利润猜测，再回查报告修正 | 每两周 1 个行业 | 能讲清「钱在哪一环」 |
| **双源交叉** | 对「市占率/增速」必须第二源 | 每次 | 单源不得写入「确定」 |
| **证伪半小时** | 研究收尾留 30 分钟专找反对证据 | 每次 | 结论里至少有 1 条风险 |
| **跟踪仪表盘** | 每标的 3–5 个可观察指标（如月销量、开工率、毛利率） | 持仓或观察名单 | 有日期、有记录，不是感觉 |
| **研报降维** | 读一篇卖方深度：划出「事实 / 推断 / 估值假设」三色 | 每周 1 篇 | 能扔掉观点只留事实表 |

**方法论第三条：** 能力来自重复「假设→L0→证伪→复盘」闭环，不是来自工具订阅数量。

### 11.5 两种切入姿势（按你习惯选）

| 姿势 | 路径 | 适合 |
|------|------|------|
| **自上而下** | 宏观粗判断 → 产业图 → 环节龙头 → 财报验证 | 周期品、政策市、你已有产业链计划 |
| **自下而上** | 先盯一家公司年报与生意 → 反推它所在产业利润池 | 消费、特色生意、巴菲特式 |

两者都要用同一套分级与证伪；差别只在**先问行业还是先问公司**。

### 11.6 工具层（辅助，不是方法论本身）

| 用途 | 建议 | 注意 |
|------|------|------|
| 归档 | 本地文件夹：`行业/公司/年报PDF/笔记.md`；或 Notion/语雀 | 文件名带日期 |
| 摘录 | 年报复制关键表到自己的「事实表」 | 区分粘贴原文 vs 自己的话 |
| 提醒 | 日历：财报季、重要公告 | 避免只靠记忆 |
| AI | 可用来**导航年报章节、翻译、归纳已提供的原文** | **禁止**把模型当 L0；关键数字必须回原文核对 |

**方法论第四条：** AI/助手 = 加速器；L0 核对责任仍在你。

### 11.7 红线（获取信息时不要做什么）

- 把付费「内幕群」、未披露重大信息当研究优势（违法且不可复盘）  
- 用 L3 传闻直接下结论  
- 只读「解读」不打开年报 PDF  
- 同时跟踪 20 个标的却没有笔记模板（信息过载 = 假勤奋）  

### 11.8 最小起步（本周就能做）

1. 选 **1 个行业 + 1 家公司**。  
2. 下载该公司最近一年年报（巨潮/EDGAR）。  
3. 建一张表，四列：`主张 | 证据 | 等级Lx | 来源`。  
4. 强制写满 10 行主张（商业模式 3、竞争 2、财务 3、治理 2），每行有等级。  
5. 花 30 分钟只做证伪。  
6. 输出一页：产业草图 + 结论 + 「我还不知道什么」。  

完成一次，比收藏 100 个信息源更接近「会获取信息」。

## 十二、知名投资机构分类 · 角色 · 组成权重

> **用途**：建立「机构版图」直觉，方便对照 §十一 流程落在哪类角色上。  
> **权重说明**：下列比例为**行业常见结构的量级估计**（按投研相关编制或核心前台人数理解），非某家公司官方编制表；同一类型里「明星工作室制」与「平台制」差异可以很大。  
> **名单**：全球标杆 + 中国市场常见名，便于检索，不构成推荐或评级。

### 12.1 按业务模式分类 + 代表机构

| 类型 | 靠什么赚钱 / 使命 | 全球知名例子 | 中国/大中华常见例子 |
|------|-------------------|--------------|-------------------|
| **A. 卖方：券商研究所 + 经纪** | 佣金、席位、投行协同；卖的是研究与通道 | Goldman Sachs、Morgan Stanley、JPM、UBS 研究端 | 中金、中信、华泰、海通、招商证券研究所 |

### 12.2 盈利来源详解（钱从哪来）

> 先分清两个概念：  
> - **机构/管理人赚的钱**（公司收入、合伙人分成）  
> - **基金/组合的投资收益**（属于出资人，管理人只按约定抽成）  
> 下表说的是前者——**这类公司靠什么养活自己、分奖金**。费率名为行业常见量级，具体以合同与监管披露为准。

#### 12.2.1 总览对照

| 类型 | 管理人主要收入 | 收入是否强依赖「投资赚得多」 | 一句话 |
|------|----------------|------------------------------|--------|
| A 卖方券商 | 交易佣金、席位费、投行费、息差等；研究多为**获客与协同** | 间接（交易活跃、投行成交才有钱） | 卖通道与服务，不是靠荐股抽成股价涨幅 |
| B 公募 | **管理费**为主；部分浮动；尾佣给渠道 | 弱–中（规模比短期收益更直接影响管理费） | 靠 AUM × 费率；规模是命根 |
| C 保险资管/理财 | 管理费、投资管理委托费；保险集团还有保费利差 | 中（要匹配负债，更厌波动） | 为负债端打工，稳健优先 |
| D 对冲/私募证券 | **管理费 + 业绩报酬**（如 2/20 变体） | **强** | 亏钱时业绩费归零，奖金弹性大 |
| E PE | 管理费（承诺/实缴资本）+ **Carry（超额收益分成）** | 中长期强（退出才大规模兑现 Carry） | 短期靠管理费活，致富靠退出分成 |
| F VC | 同 PE：管理费 + Carry | 同 PE，兑现更靠少数大成功项目 | 幂律：少数项目贡献大部分 Carry |
| G 主权基金 | 多为**国家资本、不收零售管理费**；考核投资回报 | 机构本身「盈利模式」不同于商业管理人 | 主权财富保值增值，不是卖产品给基民 |
| H 量化私募 | 管理费 + 业绩报酬；有的还有自营 | 强 | 同 D，另加重系统投入 |
| H′ 做市商（如部分 Securities） | **买卖价差**、流动性服务费 | 强依赖交易量与价差 | 与「管基金」不同，靠做市库存与价差 |
| I 家族办 | 成本中心或收服务费；不以对外销售利润为目标 | — | 花自家的钱办自家的事 |
| I′ FoF/母基金 | 管理费 + 少量业绩提成（抽下层管理人） | 中 | 赚「选人」的钱 |

#### 12.2.2 分类型说明

**A. 卖方券商（含研究所）**

| 收入项 | 含义 | 与研究的关系 |
|--------|------|--------------|
| 经纪佣金 | 客户买卖证券付的手续费 | 研报吸引机构开户、做交易 |
| 席位/综合服务费 | 公募等租用交易席位、打包服务 | 研究质量影响「席位佣金」分仓 |
| 投行承销/财务顾问费 | IPO、再融资、并购 | 研究与销售协同，但收费在投行条线 |
| 两融/衍生品/做市息差 | 融资融券利息、价差 | 偏交易与资本金业务 |
| 资管产品管理费 | 券商资管条线 | 另一块牌照 |

研究所报告通常**不直接向买方按篇卖钱**（少数独立研究另说）；盈利靠「研究 → 交易/席位/投行」的协同。

**B. 公募基金**

| 收入项 | 典型量级直觉 | 说明 |
|--------|--------------|------|
| 管理费 | 权益产品常见约按年费率 × 规模；货基等更低 | **公司收入大头**；规模上涨费涨 |
| 托管费等 | 付给托管行，不是管理人利润 | 披露在基金费用里 |
| 业绩报酬 | 部分产品有，公募里不如私募普遍 | 受监管约束 |
| 认申购费 | 常大部分给销售渠道（银行/券商/三方） | 管理人留存有限 |

投资赚 20% 不会让公司立刻多收 20% 管理费；**规模**才直接乘在费率上。业绩差 → 赎回 → 规模降 → 收入降，是间接传导。

**C. 保险资管 / 银行理财**

| 收入项 | 说明 |
|--------|------|
| 受托管理费 | 保险集团或理财子把资金交给资管团队，按规模/约定收费 |
| 保险主业利差（集团层面） | 保费投资收益 − 负债成本；资管做得好，集团利润厚 |
| 银行理财管理费 / 固定+浮动 | 理财产品向投资者收的管理类费用 |

考核常绑定**绝对收益、回撤、资产负债匹配**，不是「相对沪深 300 超多少」单一指标。

**D. 对冲基金 / 私募证券**

| 收入项 | 常见结构 | 说明 |
|--------|----------|------|
| 管理费 | 如年化约 1%–2% × AUM（国内产品各异） | 覆盖运营与底薪 |
| 业绩报酬（Incentive / Carry 类） | 如利润的 ~20%，常有高水位线 | **丰年主要奖金来源**；亏钱或未过高水位则无 |
| 自营（部分） | 用公司或合伙人资本交易 | 收益归东家 |

经典口诀「2 and 20」= 约 2% 管理费 + 20% 业绩费（现实中竞争下常被压低或改结构）。

**E. PE / F. VC（一级股权基金）**

| 收入项 | 常见结构 | 何时到手 |
|--------|----------|----------|
| 管理费 | 约 1.5%–2% × 承诺资本或实缴资本（不稳定期后常递减） | 募资后按年收，支撑团队工资 |
| Carry（附带权益） | 基金整体利润超过门槛（hurdle）后，管理人分约 **20%**（有的阶梯更高） | **项目退出**（上市、并购、回购）后分配 |
| 交易/顾问费等 | 部分基金向被投收监控费等（近年 LP 更忌讳，常冲抵管理费） | 视 LPA 约定 |

差异：PE 退出路径更清晰、单笔更大；VC **幂律**——少数明星项目贡献绝大部分 Carry，多数项目可能亏或平。

**G. 主权财富基金**

- 资本来自国家外汇、财政盈余、资源收入等，**不是向散户卖基金收管理费**。  
- 「成功」体现在：**投资回报、保值增值、服务国家战略**；内部有考核与奖金，但商业模式 ≠ 公募/私募管理人。  
- 汇金等更偏**股权管理/金融稳定**，盈利来自持股与改革，也不等于卖资管产品。

**H. 量化私募**

- 与 D 类似：**管理费 + 业绩报酬**。  
- 额外：自营盘、有时出售技术/做市（若有牌照条线）。  
- 成本结构不同：算力、数据、工程团队占比高，业绩费仍是丰年主菜。

**H′. 做市商 / 证券交易自营（如部分 “Securities”）**

- 主要赚 **bid-ask 价差**、库存风险管理收益、为交易所提供流动性的激励。  
- **不是**「研究荐股收管理费」模型；与管公募产品的资管是两条生意。

**I. 家族办公室**

- Single FO：往往是**成本中心**（家族出预算养团队），目标是家族财富保值，不对外「营利」。  
- Multi-FO：可向多个家族收**顾问费/管理费**，类似小型资管。

**I′. FoF / 母基金**

- 向出资人收管理费（通常低于底层 PE/对冲，因再抽一层）。  
- 可能收一层业绩分成（低于底层 Carry）。  
- 本质：赚**配置与选管理人**的钱，不是自己掘地挖单股的主业。

#### 12.2.3 和「角色权重」的对应直觉

| 谁贡献收入 | 组织里谁权重大 |
|------------|----------------|
| 靠交易佣金/席位 | 销售 + 能带动成交的分析师 |
| 靠 AUM 管理费 | 渠道/销售 + 能做大规模的明星经理；研究员是支撑 |
| 靠业绩报酬 | PM / 投资团队话语权与奖金弹性极大 |
| 靠 Carry（退出） | PE/VC 合伙人与项目负责人；投后影响退出质量 |
| 靠价差做市 | 交易与风控系统，不是卖方研报机器 |
| 靠选管理人 | FoF 配置与尽调团队 |

#### 12.2.4 一张图记住

```
卖「通道/服务」──── 券商经纪+投行（研究是饵）
卖「代客理财规模」── 公募、理财、保险资管（管理费）
卖「超额收益分成」── 私募证券、量化（业绩费）、PE/VC（Carry）
卖「价差/流动性」── 做市商、部分自营
不「卖产品」────── 主权基金、多数家族办（花自己的钱或国家的钱）
卖「选人能力」──── FoF / 母基金
```

| 量化研究 / 投资 | 因子、模型、回测与监控 |

### 12.4 组成权重（投研相关编制的典型量级）

下列百分比按 **「与投资决策直接相关的前台+投研人数 ≈ 100%」** 来理解；若含渠道、运营、IT，中后台往往会再占全公司很大一块（公募、券商尤甚）。

#### A. 卖方券商研究所（研究条线内部）

| 角色 | 约占比 | 说明 |
|------|--------|------|
| 行业/公司分析师（含助理） | **55–70%** | 绝对主体 |
| 销售（研究销售） | **15–25%** | 对接买方，人数随零售/机构结构变 |
| 策略/宏观/金工 | **5–15%** | 横向产品 |
| 研究所管理/质控 | **5–10%** | |

全公司若含经纪营业部、投行、IT，研究所只是一小块。

#### B. 公募主动权益（一个权益部门/公司权益条线）

| 角色 | 约占比 | 说明 |
|------|--------|------|
| 研究员（含行业组） | **40–55%** | 覆盖池支撑多只产品 |
| 基金经理 / 助理 PM | **15–25%** | 人数少、权重大 |
| 交易 | **5–10%** | 集中交易室 |
| 宏观/策略/专户等 | **5–10%** | 因公司而异 |
| 风控合规（计入投研协同） | **5–10%** | 全公司风控编制另计 |
| 产品/渠道对接（若计入） | 余下 | 很多公司渠道人数 ≫ 投研 |

**特征**：金字塔——大量研究员托少量经理；经理可同时管多产品。

#### C. 保险资管 / 银行理财（偏固收+权益配置）

| 角色 | 约占比 | 说明 |
|------|--------|------|
| 固收研究+投资 | **35–50%** | 常大于权益 |
| 权益研究+投资 | **15–30%** | |
| 大类配置 / 战略 | **10–20%** | 负债驱动 |
| 信评 / 风控 | **15–25%** | 权重显著高于纯股票私募 |
| 交易 | **5–10%** | |

#### D. 对冲基金 / 股票私募（基本面多头或多空）

| 角色 | 约占比 | 说明 |
|------|--------|------|
| 研究员 + 分析师 | **35–50%** | 平台型（Millennium 式）研究员可更多 |
| PM / 基金经理（有独立 book） | **20–40%** | 工作室制下 PM 权重极高 |
| 交易 | **5–15%** | 多空、对冲高频需求更高 |
| 风控 | **5–15%** | 平台型风控强 |
| 宏观/其他策略 | 视产品 | |

**对比公募**：总人数更少；人均 AUM 或人均决策权往往更大；「一个人既研究又下单」更常见。

#### E. PE 基金（投资部为主）

| 角色 | 约占比 | 说明 |
|------|--------|------|
| 投资团队（Deal：参谋→VP→董事总经理） | **45–60%** | 核心 |
| 投后运营 / 价值创造 | **15–25%** | 越大越专业化 |
| 融资 / 资本市场 / IR | **10–20%** | 募资与退出 |
| 法务财务中台（项目相关） | **10–15%** | 尽调协同 |

几乎**没有**传统「二级市场交易员」编制。

#### F. VC 基金

| 角色 | 约占比 | 说明 |
|------|--------|------|
| 合伙人 / 投资负责人 | **25–40%** | 决策与品牌 |
| 投资经理 / 分析师 | **40–55%** | 项目源与初筛 |
| 平台职能（人才、市场、研报） | **10–25%** | 大机构更明显 |
| 中后台 | 较小 | 常外包会计法律 |

极瘦：十人级团队管一只基金很常见。

#### G. 主权基金 / 大型养老金（配置型）

| 角色 | 约占比 | 说明 |
|------|--------|------|
| 大类资产 / 战略配置 | **20–35%** | |
| 外部管理人选型（FoF/委外） | **20–35%** | 大量资产不自己炒股 |
| 内部主动权益/固收（若有） | **15–30%** | |
| 风控、组合、运营 | **20–30%** | |

研究「选管理人、定战略」的权重大于「覆盖单股」。

#### H. 量化私募 / 系统化

| 角色 | 约占比 | 说明 |
|------|--------|------|
| 量化研究（因子/策略） | **30–45%** | |
| 工程 / 数据 / 基础设施 | **25–40%** | 权重远高于主观权益 |
| 交易 / 执行系统 | **10–20%** | |
| 风控 | **5–15%** | |
| 传统基本面调研 | **0–10%** | 基本面量化团队才有 |

#### I. 家族办公室 / FoF

| 角色 | 约占比 | 说明 |
|------|--------|------|
| 配置与管理人尽调 | **40–60%** | |
| 直投（若有） | **10–30%** | |
| 税务法律财富规划 | **15–30%** | |
| 交易执行 | 很小 | 常通道化 |

### 12.5 一张对照：谁在「做 §十一 那种研究」

| 机构类型 | §十一 基本面流程的主要承载角色 | 约占投研相关编制 |
|----------|-------------------------------|------------------|
| 卖方 | 分析师 | 最高（研究所内 55%+） |
| 公募 | 研究员为主，经理审 | 研究员 40–55% |
| 股票私募 | 研究员 + 兼岗 PM | 合计常超 60% |
| PE | 投资团队尽调 | 45–60% |
| VC | 投资团队（偏赛道与人） | 大半 |
| 量化 | 少量基本面岗或无 | 低 |
| 主权/FoF | 配置与选管理人 | 流程不同 |

### 12.6 阅读机构时的两个提醒

1. **看产品不看 Logo**：同一集团可同时有公募、私募、资管、直投。  
2. **权重随制度变**：  
   - 「明星基金经理制」→ PM 人数占比低但话语权极高；  
   - 「平台/工厂制」（多 PM book）→ PM 数量占比上升，风控占比上升；  
   - 「卖方大型研究所」→ 分析师占比最高，但个人不决策真金白银。

### 12.7 若只记一张简表

| 类型 | 人数结构一句话 |
|------|----------------|
| 卖方研究所 | 分析师海量，销售次之 |
| 公募权益 | 研究员托着少数经理 |
| 股票私募 | 人少、决策权集中、研究与下单更近 |
| PE | 投资团队+投后+IR |
| VC | 合伙人+项目经理，极瘦 |
| 量化 | 研究+工程双高峰 |
| 保险/理财 | 固收与风控权重大 |
| 主权/FoF | 配置与选人，多于自己挖地算单个股 |

## 十三、个人投资兼岗：买方研究员 + 基金经理 + 交易员

> **情境**：不加入机构编制，自己投资时一人分饰三角——**研究（买方研究员）→ 决策与组合（基金经理）→ 下单执行（交易员）**。  
> 机构里三人分职；你这里要的是**三角技能并集的最小够用集**，不是考三份岗位 JD。

### 13.1 三角各自干什么（个人版）

| 角色 | 你要完成的动作 | 产出物 |
|------|----------------|--------|
| **买方研究员** | 搞清生意、产业、报表、风险；写清逻辑与证伪 | 一页备忘录 / 事实表（主张·证据·Lx） |
| **基金经理** | 决定买不买、买多少、与别的持仓如何搭配、何时认错 | 仓位表、买入理由、退出条件 |
| **交易员** | 在可接受成本与纪律下成交；避免情绪单、追涨杀跌式冲击 | 委托记录、滑点/纪律复盘 |

### 13.2 买方研究员：技能清单

| 技能块 | 具体能力 | 对应你文档 | 深度（个人投资） |
|--------|----------|------------|------------------|
| 商业与产业 | 模式、利润池、竞争/护城河 | §十 P0、§6.A.2 | **必会** |
| 财务阅读 | 三表、现金流质量、粉饰信号 | §6.C.1/5、§三 | **必会** |
| 估值直觉 | 贵不贵、粗 DCF/倍数、情景 | §6.C.3 | **必会（粗）** |
| 治理与激励 | 大股东、激励、关联交易 | §十 P1 | **必会** |
| 信息方法论 | L0–L3、假设→证伪→复盘 | §十一 | **必会** |
| 宏观粗线条 | 利率/周期如何传到该行业 | §十、Mankiw/Marks | 够用即可 |
| 模型与写作 | 简单预测、备忘录结构 | 自学模板 | 够用即可 |
| 专家网络/路演 | 机构研究员常用 | — | **个人可弱化** |

**一句话**：研究员技能 = **会挖真相并写成可证伪逻辑**。

### 13.3 基金经理：技能清单

| 技能块 | 具体能力 | 说明 |
|--------|----------|------|
| 置信度判断 | 把研究结论变成「几成把握」 | 同逻辑不同仓位 |
| 组合构建 | 相关性、集中度、单一个股上限 | 避免「十个故事一个因子」 |
| 风险与回撤 | 最大回撤承受、杠杆/融资是否用 | 先定规则再买 |
| 仓位与加减 | 分批、金字塔、何种证据加仓/减仓 | 写进投资备忘录 |
| 基准与目标 | 你优化的是绝对收益还是相对指数 | 个人多偏绝对收益 |
| 现金与机会成本 | 何时持币、机会来了有没有子弹 | 常被业余忽视 |
| 行为纪律 | 对抗 FOMO、沉没成本、报复性交易 | Marks / 行为清单 |
| 归因复盘 | 赚亏来自逻辑对了还是β/运气 | 每季一次 |

**一句话**：经理技能 = **在不确定下分配资金与认错**，不是「又写一篇更长研报」。

研究员 vs 经理（易混点）：

| | 研究员思维 | 经理思维 |
|--|------------|----------|
| 问题 | 这家公司好不好、逻辑成不成立 | 在我的组合里值不值得占 X% |
| 失败 | 研报逻辑被证伪 | 回撤超限、或逻辑对但仓位错 |
| 时间 | 把公司研究透 | 同时盯组合、宏观边际、机会集 |

### 13.4 交易员：技能清单

| 技能块 | 具体能力 | 个人投资要到哪 |
|--------|----------|----------------|
| 交易规则 | 竞价、涨跌停、T+1、手续费、印花税、最小单位 | **必会（所在市场）** |
| 订单类型 | 限价/市价、条件单（若有） | **必会** |
| 执行纪律 | 按计划价成交，不盘中改逻辑 | **必会** |
| 冲击与流动性 | 小资金几乎无感；仓位大时要拆单、避开集合竞价混乱 | 随资金量加重 |
| 记录 | 成交价、滑点、是否偏离计划 | **必会** |
| 短线博弈/盘口语言 | Level-2、超短情绪 | **个人价值投资可弱化** |
| 衍生品对冲 | 股指期货、期权对冲 | 后置，未学透勿碰 |

**一句话**：交易员技能 = **低成本、高纪律地把决策变成持仓**，不是靠盘感「再研究一遍」。

### 13.5 三人合一：最小技能包（按优先级）

你要兼三角，建议按下面顺序练（与机构 JD 完整版不同）：

| 优先级 | 技能 | 主要对应角色 | 怎么算过关 |
|--------|------|--------------|------------|
| P0 | 产业+模式+竞争一页图 | 研究员 | 能讲清钱在哪、凭什么赢 |
| P0 | 读表+利润质量+粉饰清单 | 研究员 | 年报能自己翻、能量证据等级 |
| P0 | 投资备忘录模板（逻辑/证据/证伪/退出） | 研究员→经理 | 买入前必须有一页纸 |
| P0 | 仓位规则（单票上限、总权益敞口、现金底仓） | 经理 | 写成死规定，情绪不能改 |
| P0 | 退出与止损/止盈条件（逻辑失效优先于价格） | 经理 | 事先写好 |
| P0 | 下单与复盘纪律（计划外不交易） | 交易员 | 连续 20 笔无「冲动单」 |
| P1 | 粗估值与安全边际 | 研究员+经理 | 能说贵/便宜的理由 |
| P1 | 组合相关与行业暴露 | 经理 | 知道自己在赌几个独立逻辑 |
| P1 | 宏观传导 3 条 | 经理 | 不写宏观论文 |
| P1 | 费用与税收意识 | 交易员+经理 | 不无谓损耗收益 |
| P2 | 行为偏差清单 | 经理+交易员 | 重大决策前过一遍 |
| P2 | 跟踪指标仪表盘 | 研究员 | 持仓 3–5 个可观察指标 |
| 后置 | 杠杆、衍生品、高频盘口、专家网络 | — | 基础稳再开 |

### 13.6 一张能力地图（兼岗）

```
        ┌─ 产业/模式/竞争 ──┐
        │  财报/质量/粗估值  │──► 研究员
        │  L0 证据与证伪     │
        └────────┬───────────┘
                 │ 备忘录
                 ▼
        ┌─ 置信度与仓位 ────┐
        │  组合与回撤规则    │──► 基金经理
        │  加减仓与认错      │
        └────────┬───────────┘
                 │ 交易计划
                 ▼
        ┌─ 规则内委托 ──────┐
        │  记录与滑点复盘    │──► 交易员
        └───────────────────┘
```

**禁止的串台**：用「盘面涨了」代替研究员证伪；用「又挖到新故事」代替经理仓位规则；用「再研究研究」拖延交易员已计划好的减仓。

### 13.7 和现有学习路径怎么接

| 你已有章节 | 主要喂给谁 |
|------------|------------|
| §六 书单（财务+战略+运营） | 研究员底座 |
| §十 非财务栈 | 研究员 + 经理的仓位语境 |
| §十一 信息方法论 | 研究员主技能；经理用来审证据等级 |

### 13.8 90 天技能验收（个人兼岗）

1. **研究员**：完整做完 1 个行业 + 2 家公司备忘录（含 Lx 证据表）。  
2. **经理**：写出书面《仓位与退出宪法》并执行至少一个「模拟或小资金」组合 30 天。  
3. **交易员**：所有成交有计划编号；复盘「计划外交易」次数 → 目标为 0。  

三项都过，才算三角技能闭环上线；之前继续补书与 §十一 练习即可。

### 13.9 三角技能：学习资料与「同行经验」从哪来

> **原则**：书/股东信为主；播客与访谈为辅；券商研报当 L2 线索。  
> **「同行经验」对个人投资者** = 公开的基金经理书信、访谈、备忘录范文、交易复盘，不是内部路演纪要。  
> 与 §六书单重叠处只列**最贴三角岗位**的；底座教材仍回 §六 / §十。

#### 13.9.1 怎么学「同行经验」（方法比书单更重要）

| 做法 | 具体 |
|------|------|
| 读股东信/季报信 | 只划三类句子：事实、判断、仓位/纪律；对照自己备忘录缺哪类 |
| 倒推一笔公开持仓 | 用当时年报验证「他可能看了什么 L0」（练习研究员视角） |
| 抄结构不抄结论 | 复制备忘录标题结构（生意/竞争/财务/估值/风险/退出），禁止抄评级 |
| 建「别人踩坑」本 | 每次读到回撤、误判、治理翻车，记一条可检查规则 |
| 少追荐股社群 | L3 噪音；同行经验以**署名、可复查、带过程**的文本为准 |

#### 13.9.6 到哪里找「活着的同行声音」（辅助）

| 类型 | 例子 | 用法 |
|------|------|------|
| 股东信 / 备忘录 | Berkshire letters；Oaktree Insights | **主菜** |
| 长访谈 | 老牌管理人深度访谈（视频/文字） | 只记流程与原则，忽略荐股 |
| 播客 | 英文如 Invest Like the Best 等（质量不均） | 通勤辅助；结论回 L0 验证 |
| 持有人大会实录 | 部分基金公开答问 | 看如何解释回撤与持仓逻辑 |
| 同好社群 | 读书会、年报共读（非荐股群） | 练表达与证伪，设信息分级纪律 |

#### 13.9.7 明确不当作「同行经验」的

- 付费荐股群、盘中喊单、神秘「内幕」  
- 只给目标价不给证据链的「研报摘要」二次传播  
- 满屏收益截图无过程的社交帖  

#### 13.9.8 明星投资人适读表（巴菲特 / 芒格 / 段永平等）

> 问的是：**适不适合当你「研究员+经理+交易员」兼岗的同行教材**，不是谁更神、该不该抄作业。  
> 评判维度：对三角色哪头有用、文本是否公开可复查、与 A 股/个人约束的差距、常见误用。

| 人物 | 适不适合你 | 主要喂谁 | 学什么 | 别学什么 / 注意 |
|------|------------|----------|--------|-----------------|
| **巴菲特 Warren Buffett** | **很适合（主菜之一）** | 研究员+经理 | 生意质量、管理层与资本配置、长期持有与安全边际、股东信写作结构 | 别模仿其保险浮存金与并购能力；晚年持仓≠你的能力圈；交易员技能几乎不教 |
| **查理·芒格 Charlie Munger** | **适合（思维层）** | 经理+研究员 | 跨学科模型、逆向思考、激励机制、避免蠢错 | 语录易变成鸡汤；少具体建模与财报步骤；《穷查理宝典》宜精读「心理学倾向」等章，勿当荐股手册 |
| **段永平** | **很适合（中文主菜）** | 研究员+经理 | 商业常识、消费/科技产品体感、集中持股与「不懂不做」、跟巴菲特同构但话语更口语 | 持仓极集中、时代与信息优势难复制；雪球/访谈里的具体标的当案例不是信号；几乎不教短线交易 |
| **霍华德·马克斯 Howard Marks** | **很适合（经理主菜）** | 经理 | 风险、周期、第二层思维、仓位与情绪 | 偏债务/信用出身，股票产业细节要另补 |
| **彼得·林奇 Peter Lynch** | **适合（研究员草根）** | 研究员 | 从生活观察生意、分类公司、十倍股叙事 | 其年代调研条件与换手习惯难复制；别学成高频打板 |
| **李录** | **适合（桥接中美价值）** | 经理+研究员 | 价值投资在中国语境的理路；能力圈与制度差异 | 公开材料相对少，质量高；作补充不是唯一来源 |
| **格雷厄姆 Benjamin Graham** | **适合（纪律底座）** | 研究员+经理 | 安全边际、先生投资后投机、定量保守 | 净净营运资本等经典招式在今日 A/美股要改装；文风老 |
| **塞斯·卡拉曼 Seth Klarman** | **适合（进阶经理）** | 经理 | 《安全边际》式买便宜与风险优先 | 正版难寻、市场环境变了；作原则书 |
| **雷·达利欧 Ray Dalio** | **有条件适合** | 经理（宏观/原则） | 原则化决策、压力测试思维、《原则》复盘文化 | 全天候与桥水宏观机器个人难仿；别当成选股教程 |
| **索罗斯 / 宏观传奇** | **暂不作为主教材** | — | 反射性等概念可了解 | 与你当前「读企业」主线距离远；杠杆与宏观对赌风险高 |
| **短线/游资明星** | **不适合你当前三角定位** | — | — | 与 §13 交易员「弱化盘口」冲突；易毁仓位宪法 |

**三人怎么搭配（你点的巴菲特、芒格、段永平）：**

```
段永平（中文、商业体感、能力圈） 
    + 巴菲特股东信（资本配置与长期主义范文）
    + 芒格（少犯蠢的思维清单）
    + Marks 备忘录（仓位/周期/风险——补经理短板）
```

- **研究员课**：段永平式「产品与常识」+ 巴菲特式「经济商誉/护城河语言」+ 你自己的年报 L0。  
- **经理课**：Marks 为主，巴菲特/段永平教「重仓但先懂」；芒格教「什么绝对不碰」。  
- **交易员课**：三者都**几乎不教**盘感——继续用 §13.4 +《交易心理分析》+ 日志；他们示范的是「少交易」。

**适读结论：**  
巴菲特、芒格、段永平**都合适**，且与价值兼岗高度同向；建议**段永平（中文入口）+ 巴菲特信 + 芒格精读 + Marks**，不要只追三人语录合集。具体买卖点以你的备忘录与仓位宪法为准，不以明星持仓为信号。

## 十四、市场投资角色分类与大概占比

> **用途**：弄清「你听说的机构占大多数」在什么口径下成立。  
> **关键**：占比有两种完全不同的尺子——**持股市值（谁拿着）** vs **成交额（谁在买）**；美股与 A 股结构也不同。  
> **数据**：下列为公开研究/统计的**量级**（约 2024 年末–2025 年），会随行情变动；不作精确到小数点的承诺。

### 14.1 先分清三种「角色」说法

| 说法 | 指什么 | 别和什么混淆 |
|------|--------|--------------|
| **市场参与者 / 持股结构** | 按持有股票市值划分：个人、公募、保险、外资、产业资本等 | 不是券商研究所里的「分析师编制」 |
| **机构内岗位** | 研究员、基金经理、交易员（§十二、§十三） | 岗位占比 ≠ 市场资金占比 |
| **你个人兼岗** | 一人扮演买方研究+经理+交易 | 在统计上仍算**个人投资者**（除非你管的是持牌产品） |

### 14.2 市场参与者分类（通用标签）

```
证券市场资金方
├── 个人投资者（零售）
│     ├── 一般个人账户
│     └── 个人大股东 / 高管持股（有的统计单独拆出）
├── 产业资本 / 一般法人
│     └── 上市公司大股东、非金融企业交叉持股等（锁仓属性强）
├── 境内专业机构投资者
│     ├── 公募基金
│     ├── 私募证券 / 对冲
│     ├── 保险资金
│     ├── 养老金 / 社保 / 年金
│     ├── 银行理财 / 信托等
│     └── 券商自营等
├── 政府 / 「国家队」相关持股（汇金、证金、财政持股等，口径因报告而异）
└── 外资（陆股通、QFII/RQFII、海外账户等）
```

卖方券商、投行：**不是**上表「持股大户」的主分类；他们提供通道与研究，自营另计在机构里一小块。

### 14.3 A 股：持股市值大概占比（流通市值口径）

综合券商「投资者结构全景」类跟踪（如申万宏源 2024 年末「五分法」、华西等 2025 季报口径），**量级**如下：

#### （1）粗分四类（流通市值，约 2024 末–2025）

| 类型 | 约占流通市值 | 说明 |
|------|--------------|------|
| **一般法人 / 产业资本** | **约 35%–47%** | 常是最大头；含产业股东，不全是「主动做投资组合」的机构 |
| **个人投资者** | **约 30%–34%** | 一般个人仍很大；2024 末约 32% 量级，2025 有季报回升到约 33% |
| **境内专业机构** | **约 18%–23%** | 公募+私募+保险+养老金等合计 |
| **外资** | **约 3.5%–4.5%** | 低于 2021 高点（约 5%+） |

> 所以：若把「一般法人」也算宽口径机构，会说机构占比高；若只看**专业投资机构**，A 股专业机构约两成，**个人仍占三成左右**——并不是「机构已经占绝大多数（像美股那样）」。

#### （2）专业机构内部（占全市场流通市值的量级）

| 机构类型 | 约占流通市值 | 备注 |
|----------|--------------|------|
| 公募基金 | **约 7%–8%** | 专业机构里通常最大单类 |
| 保险 | **约 3.5%–4%** | 中长期资金 |
| 私募证券 | **约 2%–2.5%** | |
| 养老金等 | **约 1.5%–2%** | |
| 其他（券商、信托等） | 各约 1% 上下 | |

申万宏源 2024 年末五分法另一口径：产业资本约 **34%**、政府持股约 **8%**、专业机构约 **19%**、个人大股东约 **6%**、一般个人约 **32%**（与上表同一量级、拆法略有不同）。

#### （3）自由流通口径（更能反映「能交易的筹码」）

剔除长期锁定的产业股后，**境内外专业机构合计**常到自由流通的 **约 40%–45%** 量级；个人及其他合计仍可过半。公募在自由流通里占比可升到约 **14%–15%** 量级。

#### （4）成交额口径（和「谁主导市场风格」更相关）

A 股历史上个人在**成交**中占比长期很高；近年机构交易占比上升，有跟踪称机构交易占比已可到 **约 30%+** 量级，但个人仍常是交易活跃的主力之一。  
→ **持股**上法人+个人都大；**交易**上个人声音往往更响——这是 A 股和美股体感差异的重要原因。

### 14.4 美股：为何常说「机构占大多数」

| 口径 | 大致图景 |
|------|----------|
| **机构 vs 零售持股** | 代理季等统计里，零售受益所有权约 **三成** 量级（如 Broadridge 2024 季约 **31.7%**），则机构侧约 **七成** 量级；学术样本中位机构持股亦常在 **约 67%–70%** |
| **家庭部门** | 美国家庭大量股票是**间接**持有（共同基金、养老金、401k），钱在「家庭」名下，**投票与选股常由机构代劳** |
| **直接买个股的家庭** | 有股票的家庭比例高，但「自己挑个股」仍显著少于「通过退休账户/基金间接持有」 |

因此：  
- 「美股机构占大多数」在**持股与定价主导权**意义上大体成立（机构约七成量级）。  
- 「A 股」若只比**专业机构**，约两成，**不能**照搬美股那句口号；个人直接持股约三成仍很显眼。

### 14.5 「机构投资者占大多数」——怎么理解才准确

| 市场 | 更准确的说法 |
|------|----------------|
| **美股** | 机构在持股与定价中占主导，大体成立 |
| **A 股** | **产业法人持股最大；专业机构约两成；个人约三成**。若听说「机构占大多数」，要问对方是否把产业资本算进去，或是否指自由流通/成交里的机构行为 |
| **你自己** | 用自有资金投资 → 统计上是**个人投资者**；技能上可按 §十三 学机构买方三岗 |

### 14.6 和你学习路径的关系

| 市场角色 | 行为特征（简化） | 你要对齐的技能 |
|----------|------------------|----------------|
| 个人投资者 | 信息散、情绪交易多、寿命短逻辑多 | 用机构式备忘录与仓位宪法**降维打击自身弱点** |
| 公募/保险等 | 考核、规模、相对基准 | 学其研究深度，慎学其「排名压力」 |
| 私募/对冲 | 业绩费、灵活 | 学其证伪与仓位，慎学杠杆 |
| 产业资本 | 控制权、战略持股 | 懂其动机（增持回购≠价值信号必然） |
| 外资 | 配置与流动性敏感 | 作边际定价力量之一，不作唯一罗盘 |

### 14.7 数据来源（便于你自行更新）

| 市场 | 可跟踪来源 |
|------|------------|
| A 股 | 券商「投资者结构全景」定期报告（申万、华西等）；基金季报持仓；央行储户调查（居民意愿，非持股） |
| 美股 | 美联储 Z.1 Financial Accounts；各指数公司/学术对 institutional ownership 的统计 |

### 14.8 一句话备忘

```
美股：机构主导持股与定价（家庭钱也多在产品里）。
A股：法人产业股最大 + 个人约三成 + 专业机构约两成；
     「机构占大多数」要先问清口径。
你：身份是个人，方法学买方机构。
```

## 十五、博弈论与本主题的关系 · 放在哪一层

> 对应你截图里的书单：Dixit《策略思维》/《妙趣横生博弈论》、牛津通识《博弈论》、Axelrod《合作的进化》、Annie Duke《对赌》等。  
> **结论：有关，但是「决策操作系统」补丁，不是财务/产业主菜的替代。**

### 15.1 和当前主题的关系（有没有关）

| 你在学的主题 | 博弈论帮什么 | 帮不了什么 |
|--------------|--------------|------------|
| **买方研究员** | 想清产业里多方怎么出招（产能竞赛、价格战、标准战、供应商锁定） | 不代替年报 L0、护城河事实 |
| **基金经理** | 零和/正和、重复博弈、承诺与退出成本 → 仓位与对手行为直觉 | 不代替仓位宪法与估值 |
| **交易员（你的弱化版）** | 信息劣势、别被「结果偏见」审判单笔 | 不教盘口技术 |
| **管理学 / 经营** | 激励相容、合作如何维持（Axelrod） | 不代替运营与管会 |
| **产业分析** | 把五力里的「互动」说清楚 | 不代替利润池数据 |
| **Marks / 段永平式纪律** | 《对赌》补「好决策 ≠ 好结果」的复盘语言 | 与价值投资同向，非冲突 |

截图路径（**一本 Dixit +（可选）牛津通识 +《合作的进化》**，决策向再加《对赌》）与你「经世致用、不搞学术博弈论」一致，可直接采用。

### 15.2 在知识地图里的位置

```
宏观粗线条
    ↓
产业 / 竞争（Porter 等）──── 博弈论：解释「多方同时行动时会怎样」
    ↓
公司生意 + 财务 L0
    ↓
投资决策（仓位 / 买卖）──── 博弈论 +《对赌》：决策质量与复盘
    ↓
执行纪律（交易日志）
```

更短一句：

| 层 | 内容 | 博弈论 |
|----|------|--------|
| **对象层** | 产业、财报、估值（§六、§十） | 很少直接提供数字 |
| **互动层** | 竞争者、客户、监管、其他资金怎么反应 | **主要落点** |
| **决策层** | 置信度、仓位、认错（§十三经理） | **强相关**（《对赌》、Dixit 决策四问） |
| **执行层** | 下单纪律 | 弱相关（防结果偏见即可） |

相对 MBA 课表：最靠近 **经理经济学 / 策略里的「互动与激励」**，不是会计、不是估值主课。

### 15.3 对接三角角色的用法

| 角色 | 怎么用截图里的工具 |
|------|-------------------|
| 研究员 | 分析六问：参与人、策略、收益、信息、是否重复、均衡落哪——写进产业一页图旁注 |
| 基金经理 | 决策四问：零和还是正和、一次性还是重复、承诺/退出成本、谁更缺信息——写进备忘录「博弈备注」 |
| 交易员 | 《对赌》：用过程质量复盘，避免「赚了就证明逻辑对」 |

### 15.4 和现有书单的优先级（避免抢主线）

| 优先级 | 材料 | 说明 |
|--------|------|------|
| P0 主线仍是 | 财报、产业、Marks、段永平/巴菲特信、仓位宪法 | 博弈论插队不应压过这些 |
| P1 决策补丁 | Dixit **只选一本**（更建议《策略思维》） | 与截图结论一致；两本 Dixit 不必都读 |
| P1 | 《合作的进化》 | 补长期合作/背叛，职场与商业关系也用得上 |
| P2 | 牛津通识《博弈论》 | 1–2 天术语地图，可选 |
| P2 | 《对赌》 | 经理复盘专用，模型书读完后或并行浅读 |

### 15.5 一句话

博弈论 = 给你的投资地图加一块 **「别人会怎么动」的透镜**；放在 **产业竞争与投资决策之间**，服务研究员互动分析与基金经理决策质量，**不是**第三套财务体系。
