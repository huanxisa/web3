## 📐 方向总览（总控视角 — 子 agent 必读，你执行前也看一眼）

> **W8 是差异化叙事周** — 前 7 周已覆盖 DEX / 借贷 / 稳定币 / LST / 撮合 / MPC / 多签 七大主线，简历 80% 通用度已经够。
> W8 的目的是**给某类公司面试时多一张牌**。三选一里你只挑一个，**先看选择决策树**。

### A. 项目抉择 — 三选一决策树（请按"目标公司池"先选定 1 个）

| 选项 | 业务定位 | JD 数据 | 选它的理由 / 不选的理由 |
|---|---|---|---|
| **① EigenLayer**（restaking）| ETH 再质押基础设施，目前 TVL 第二 | Staking/LST/LRT 方向 **15** 命中里 1/3 是 restaking 公司（EigenLayer/Ether.fi/Renzo/Puffer）| ✅ 选它：如果你瞄准 Ether.fi / Renzo / Puffer / EigenLabs / Symbiotic 这些 restaking 公司 ❌ 不选：业务复杂（AVS / Operator / Slasher 三方），1 周吃不深 |
| **② LayerZero V2**（通用跨链桥）| 跨链消息协议标准之一，覆盖 70+ 链 | 跨链方向 **12** 命中（Wormhole / LayerZero / Axelar / Chainlink CCIP 均高频）| ✅ 选它：如果你瞄准 LayerZero / Wormhole / Axelar / Across / Hop 这些桥公司，**全 Go 后端 worker**对口 ❌ 不选：业务更"基建"少业务，叙事时不够亮 |
| **③ Pendle V2**（利率衍生品）| YT / PT 分离的利率市场，DeFi 里**最业务密集**的协议之一 | DeFi 协议 42 命中里 ~3 个是利率/收益方向 | ✅ 选它：如果你瞄准 Pendle / Spectra / Ethena 这类高叙事 DeFi ❌ 不选：JD 量小（只在 DeFi 协议团队提及），通用度低 |

> **总控推荐排序（按"通用度 × 命中量"）**：
> 1. **首选 ② LayerZero V2** — 桥方向命中最大且全 Go 仓库对口你最强
> 2. 次选 ① EigenLayer — restaking 是叙事最热的方向，简历亮眼
> 3. 备选 ③ Pendle — 适合"我就想做 DeFi 协议工程师"的明确目标
>
> **决定后**：把本文件里 §A 之外所有"三选一"占位都替换成你选定项目的具体内容；下面 §C/§D/§E 我提供 3 个项目各自的版本，**选完后只保留一个**。

### C-① EigenLayer 选项的仓库 & 系统设计

#### 仓库分级（已 clone）

| 仓库路径 | 等级 | 必看模块 | 后端价值 |
|---|---|---|---|
| `repos/innovation/eigenlayer-contracts/src/contracts/core/StrategyManager.sol` | 🔴 必看 | deposit/withdraw 接口 + events | LST → restaking 的入口流 |
| `repos/innovation/eigenlayer-contracts/src/contracts/core/DelegationManager.sol` | 🔴 必看 | 委托给 Operator 的状态机 | 简历中"Operator/Staker 关系图"的数据来源 |
| `repos/innovation/eigenlayer-contracts/src/contracts/core/AVSDirectory.sol` | 🔴 必看 | AVS 注册 / Operator opt-in | restaking 业务核心 |
| `repos/innovation/eigensdk-go/` | 🔴🔴 **必看，王炸** | **官方 Go SDK，AVS Operator 开发模板** | **PoC 直接基于此扩展** |
| `repos/innovation/eigenda/` | 🟡 参考 | EigenLayer 上线第一个 AVS（数据可用层） | 看一个完整 AVS 长什么样 |

#### 2 道系统设计题

- **#1 Restaker 收益聚合后端**：监听 deposit/withdraw/delegate 事件 → 聚合每个 staker 在多个 AVS 上的奖励（按 Operator → AVS → strategy 多级聚合）→ REST 接口给前端看「我的总 APR」
- **#2 AVS Operator 节点监控**：用 `eigensdk-go` 起一个最小 AVS Operator → 监控 task 接收 / 执行 / slash 风险 → Prometheus metrics + 告警

> ⚪ **未 clone 但强烈建议补**：[LayerZero-Labs/lz-evm-worker-example](https://github.com/LayerZero-Labs/) — DVN/Executor Worker 的 Go/TS 完整范例工程

#### 2 道系统设计题

- **#1 DVN 验证后端**：跑一个 DVN（Decentralized Verifier）→ 监听源链 `PacketSent` → 验证 → 在目标链 `commitVerification` → 含失败重试 / 多链 RPC 管理
- **#2 跨链消息状态查询服务**：indexer 监听所有支持链的 EndpointV2 → 把每条 message 的「sent → verified → delivered → failed」状态聚合 → REST/WS 查询接口（类似 LayerZero Scan）
